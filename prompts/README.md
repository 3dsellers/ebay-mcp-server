# Ready-made prompts for 3Dsellers MCP

Copy a prompt into Claude, ChatGPT or any assistant connected to 3Dsellers. Replace the parts in {braces}. Every prompt reads first and asks before it changes anything.

## 1. Morning check
Good morning. For each of my stores, show today's new orders, the orders still waiting to ship and the unread buyer messages. Don't change anything.

## 2. List a product on eBay
Create a listing for the product with SKU {SKU} and publish it to my eBay store {store}. Check the category mapping and the required item specifics first, show me the draft, and publish only after I approve.

## 3. Cross-list best sellers
Find my 20 best-selling eBay products that are not listed on {channel}. Show me the list, then publish the ones I approve.

## 4. Fix missing item specifics
Find active eBay listings with no Brand or MPN. Suggest values from the title and description in a table, and update only the rows I approve.

## 5. Stock check
Which products have fewer than {N} in stock? Compare warehouse stock with each channel and fix the quantities that don't match after I confirm.

## 6. Bulk price change
Raise the price of every listing in the segment {segment} by {X}%. Do a dry run first, tell me how many listings will change, and run it only after I confirm.

## 7. Buyer messages, returns and cases
Show unanswered buyer messages, returns and cases from the last 3 days. Draft a short, polite reply to each one and send nothing until I approve each reply.

## 8. Promoted Listings review
Show my eBay Promoted Listings campaigns from the last 30 days with ad fees, sales and ROAS. Suggest which to pause or change, and change nothing until I say so.

## 9. Supplier CSV
Import this supplier file as a dry run, show the rejected rows and why, then run the real import after I approve.

## 10. Weekly report
Every Monday, export all active listings with price, quantity and channel.

## 11. Monthly eBay money check
Show what eBay paid me this month, the money still on hold, and any open payment disputes with their deadlines. Don't change anything.
